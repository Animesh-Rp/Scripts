# Shell scripts

Portable `sh` / `bash` / `zsh` scripts that run on macOS, Linux, and WSL.

**Test:** if you wouldn't be embarrassed to run it on a fresh Ubuntu container *and* a fresh macOS terminal, it belongs here.

If something is macOS-only (uses `osascript`, `defaults`, Homebrew paths) or Linux-only (uses `apt`, systemd), put the platform in the filename — e.g. `mac-flush-dns.sh`, `linux-cleanup-snap.sh` — and note it in the script header.
